## 1. App goal

**MindFlow** (internal package name: `project484`) — a Flutter mobile app for mental wellness + productivity, **iOS-targeted** (Android works for development on Windows).

Six-step user flow:
1. Emotional check-in (mood)
2. Capture thoughts via voice or text
3. Sort thoughts: release (let go) vs action (turn into tasks)
4. Convert actionable thoughts into to-do tasks
5. Run focused work sessions (Pomodoro) and breathing exercises
6. Track progress through personalised insights

Tone: calm, soft, supportive — never clinical.

## 2. Currently implemented features

### Auth (Supabase + local fallback)
- Login / Sign Up tabs on `/login`. Email + password.
- `AuthService` ([lib/features/auth/data/auth_service.dart](lib/features/auth/data/auth_service.dart)) abstracts Supabase or local-only mode.
- Sign Up creates Supabase user with `name` in user metadata. Email confirmation flow handled (`AuthResult.needsEmailConfirmation`).
- Sign In uses `signInWithPassword`. `AuthException` mapped to user-friendly SnackBar.
- Sign Out wired in Home greeting (tap bell icon → bottom sheet → Sign out → clears UserSession + OnboardingStorage + Supabase session).
- Router (`AppRouter._redirect`) gates all tab and onboarding routes on `AuthService.instance.isSignedIn`. `_AuthRefreshNotifier` listens to Supabase auth stream and re-runs redirect on state change.
- iOS-style transitions: `CupertinoPage` for stack routes (login + onboarding).

### Onboarding (7 screens)
1. Welcome — gradient logo + "We have 6 quick questions"
2. Age + Role — chips (16-18, 19-22, etc.) + cards (student, working, both, transition)
3. Stress sources — multi-select chips (max 3)
4. Stress response — freeze / overthink / procrastinate / distract
5. AI tone — direct / warm / coach / reflective (with example quote)
6. Goals + Frequency — rank top 2 goals + days/week slider
7. Ready — animated logo, "Start my first release" CTA

Data persisted to `shared_preferences` via `OnboardingStorage`. Hydrated at startup in `main.dart`.

### Home (`/home`)
- Greeting changes by hour (Good morning / afternoon / evening / night) and uses `UserSession.displayName`.
- Bell icon → sign-out bottom sheet.
- Mood check-in card (horizontal scrollable mood chips).
- "What's on your mind?" capture card with **Speak** and **Write** buttons.
- Recent activity tiles below.

### Speak (Voice Capture Modal)
- Real STT via `speech_to_text` package, locale `en_US`.
- Pulsing mic button + animated audio wave + live transcript.
- Save calls `ThoughtRepository.addThought(content: transcript)` and emits `ThoughtFeed.notifyChanged()`.
- Auth errors caught → SnackBar.

### Write (Text Capture Modal)
- Bottom sheet with multiline TextField, sentence capitalisation.
- Save → `addThought(content: text)` → `ThoughtFeed.notifyChanged()`.

### Release (`/release`)
- Reads from `ThoughtRepository.fetchReleaseThoughts()`. **No mock seed.**
- Each card is a `LongPressDraggable<Thought>`. Long-press (~250ms) → drag.
- Bottom-fixed `🗑️` `DragTarget`. Drop → `releaseThought(id)` → `is_released = true`. Card disappears.
- Soft release only (no hard delete from UI).
- `ThoughtFeed.revision` listener auto-refreshes after Speak/Write.
- Loading / error / empty states styled consistent with the rest of the app.

### To-Do (`/todo`)
- Tasks generated by `TaskRecommender` from onboarding answers (stress sources → task templates, role → fillers, goals + tone → "Why this matters" copy, stress response → which task is flagged).
- Filter chips (All / Work / School / Family / Personal). Pastel category pills. Round checkbox toggles done state.
- Tasks are NOT yet persisted to Supabase (mock recommender output only).

### Focus (`/focus`)
- Mode switch: **Timer** (Pomodoro 25/5 min) and **Breathing**.
- Breathing: 4 presets (Box 4·4·4·4, 4·7·8, Coherent 5·5, Belly 4·6). Each maps to a `stressResponse` and is marked "For you".
- Animated session: scaling gradient circle + phase labels + cycle counter. Haptic on start/stop/finish.

### Insights (`/insights`)
- `InsightsProvider.snapshot()` builds personalised data:
  - **Captured** stat: live count from `fetchReleaseThoughts()`
  - **To-do** stat: from `TaskRecommender.recommend()`
  - **Goal** stat: `OnboardingData.weeklyFrequency`
  - **Tone** stat: AI tone selection
  - **Weekly insight** message: dynamic, blends tone + first stress source + capture count
  - **Top concerns**: top 3 from `OnboardingData.stressSources` (45/30/25%)
- `ThoughtFeed.revision` listener — auto-refreshes when capture happens.

### Cross-cutting
- `ServiceLocator` ([lib/data/service_locator.dart](lib/data/service_locator.dart)) returns `MockThoughtRepository` if Supabase config blank, else `SupabaseThoughtRepository`.
- `ThoughtFeed` ([lib/data/thought_feed.dart](lib/data/thought_feed.dart)) — `ValueNotifier<int>` for cross-screen refresh.
- iOS niceties: portrait lock, dark status bar icons, haptic feedback on key interactions.
- `google_fonts` runtime fetching disabled (no DNS-broken-emulator crashes); falls back to system font when offline. Bundle Poppins .ttf as assets to restore brand font.

## 6. Important rules

- **DO NOT redesign UI.** Existing visual language (cards, spacing, typography, gradients, bottom nav) is locked.
- **Keep the existing design system.** Tokens live in `lib/core/theme/`. Never invent new colors. Onboarding has its own namespaced `onb*` tokens; don't bleed those into the rest of the app.
- **No mock data on Release after Supabase is connected.** `MockThoughtRepository._store` starts empty. `MockData.tasks/insightStats/concerns` already removed.
- **Home Write/Speak must save thoughts** via `ThoughtRepository.addThought(content: ...)` and call `ThoughtFeed.notifyChanged()`.
- **Release fetches from `ThoughtRepository.fetchReleaseThoughts()`** — never reads constants. Auto-refreshes via `ThoughtFeed`.
- **Drag-to-trash sets `is_released = true`** via `releaseThought(id)`. Never hard-delete from UI. `deleteThoughtPermanently` exists in the repo for future "clear history" but is unused.
- **iOS-targeted**: prefer `CupertinoPage` for stack transitions, `HapticFeedback.selectionClick / lightImpact / mediumImpact` on interactive widgets, `SafeArea` everywhere.
- **GitHub push only on the phrase "githuba güncelle"**. Before pushing, scan `supabase_config.dart` for accidentally-committed live keys.
- **Reply in Turkish, end every reply with a short "Bu turda yapılanlar" recap.**

## Quick reference: how to test the full thought flow

1. Sign Up: enter name/email/password → Create account → onboarding → Ready → `/home`
2. Tap **Write** → type a thought → Save
3. Bottom nav → **Release** → card appears (live transcript or typed text)
4. Long-press card (~250ms) → drag to 🗑️ at bottom → drop
5. Card disappears, snackbar "Thought released."
6. In Supabase mode: row in `public.thoughts` now has `is_released = true`
